# Failure Modes

- Ohne Angabe zur Kundensituation wird der Text generisch und wirkt wie eine
  Vorlage.
- Das Modell ergaenzt bei duennen Stichpunkten gern Leistungen, die nie
  besprochen wurden. Der Entwurf muss deshalb immer gegengelesen werden.
- Bei Preisvorgaben im Eingabetext besteht die Gefahr, dass daraus ein
  scheinbar verbindliches Angebot wird.
- Fachbegriffe aus dem Gewerk werden manchmal falsch verwendet.
- Fuer oeffentliche Ausschreibungen ist der Prompt nicht geeignet.
- Der Prompt trifft keine Aussagen zu Gewaehrleistung oder Haftung und
  ersetzt keine rechtliche Pruefung.

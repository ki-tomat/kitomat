KItomat Review-Agent 2.0

Übergabe am 3. August 2026 · Review-Team · Branch review/pre-review-wizard

Ein KI-Agent prüft eingereichte Beiträge automatisch in sieben Phasen, vergibt einen Ampelstatus und legt das Ergebnis einem menschlichen Reviewer vor — entscheiden darf er nichts.

Der Ablauf

Zwei Wege in den Review. Manuell über review/intake/ — funktioniert sofort, ohne Workflows, ohne Label. Oder automatisch über das Label review-required an einem Pull Request.

Beitrag aus review/intake/ oder Pull Request mit Label │ ├─ PHASE 0 Sicherheitsprüfung, rein lokal auf dem Server │ Findet sie personenbezogene Daten → STOPP. │ Es wird nichts an eine KI übertragen. │ ├─ PHASE 1-6 Potenzial und blinde Flecken · Pflichtdateien · │ Metadaten und Trust Layer · Peer Review · │ Szenario-Triade · Rückmeldung │ ├─ Ampel + drei Berichte + E-Mail an die Reviewer-Gruppe │ ├─ REVIEWER prüft im Cockpit, übersteuert bei Bedarf, │ gibt jedes Gate einzeln frei │ └─ MAINTAINER entscheidet über Merge und Status

Drei Zusagen — technisch erzwungen, nicht nur versprochen

1 · Der Agent entscheidet nichts Kein Status, kein Merge, keine Veröffentlichung. In jedem Ergebnis steht human_decision_required: true. Erlaubt sind nur drei Empfehlungen.
2 · Kein Gate durch eine KI Vier Bedingungen: kein Blocker, kein P0, alle Pflichtbestätigungen, Unterschrift des Reviewers. Diese Prüfung enthält keinen Modellaufruf.
3 · Keine Daten ungeprüft nach draußen Die Sicherheitsprüfung läuft lokal, bevor eine KI den Beitrag sieht. Bei einem Treffer endet der Lauf nachweisbar ohne Übertragung.

Die Ampel

FarbeBedeutungNächster Schritt
RotBlockierender Befund oder P0Zurück an die beitragende Person
GelbNachbesserung oder Trust Review nötigJe nach Befund
GrünNichts Blockierendes gefundenReviewer kann freigeben

Grün heißt nicht „freigegeben". Grün heißt: bereit, dass ein Mensch freigibt. Diese Formulierung stammt wörtlich aus den bestehenden KItomat-Unterlagen.

Alle vier waren formal korrekt und inhaltlich falsch. Keiner wäre ohne Lauf an echtem Material aufgefallen.

# Prompt-Paket: TEST – AP14 Einreichungsablauf September 2026

## Szenario-Triade

### Positiv
Eine Person erstellt mit dem Prompt eine klare Checkliste für eine fiktive Einreichung.

### Nachbearbeitbar
Die Checkliste ist brauchbar, muss aber an einen fiktiven Artefakttyp angepasst werden.

### Negativ
Bei echten Personen-, Kunden- oder internen Unternehmensdaten darf der Prompt nicht verwendet werden..
